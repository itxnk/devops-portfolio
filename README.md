# DevOps Portfolio

A responsive portfolio website showcasing DevOps, cloud-native, and software delivery projects.

## Live site
After enabling GitHub Pages, the site will be available at: https://itxnk.github.io/devops-portfolio/

## Projects
- [Dockerized Full-Stack App](https://github.com/itxnk/dockerized-fullstack-app)
- [Kubernetes GitOps Lab](https://github.com/itxnk/kubernetes-gitops-lab)
- [Terraform AWS Infrastructure](https://github.com/itxnk/terraform-aws-infrastructure)

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Push to `main` or run the `Deploy portfolio to GitHub Pages` workflow manually.

The included workflow publishes the site using GitHub Pages Actions.

## Customize
Edit the project cards and profile links in `index.html`. Update skills and contact links before sharing publicly.
